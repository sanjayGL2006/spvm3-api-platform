SPVM3 API Log in / Register

Programming knowledge, one API key away.

Register, create your own API key, and search or ask questions across programming languages, Git, GitHub and more. Every key has scopes, an optional expiry, its own rate limit, and can be rotated or revoked any time.

Get your API key

1. Register

Create a free account with your email and a strong password.

2. Create a key

Choose scopes and an expiry. The full key is shown only once.

3. Call the API

Send the key in the X-API-Key header. See usage per key in your dashboard.

Quick start

Search the knowledge base (needs the knowledge:read scope):

curl "https://YOUR-HOST/v1/knowledge/search?q=python%20list" \
  -H "X-API-Key: spvm_live_..."

Ask a question (needs the ask scope):

curl -X POST "https://YOUR-HOST/v1/ask" \
  -H "X-API-Key: spvm_live_..." -H "Content-Type: application/json" \
  -d '{"question": "What is git rebase?"}'

Python:

import requests
r = requests.get("https://YOUR-HOST/v1/knowledge/search",
                 params={"q": "python list"}, headers={"X-API-Key": "spvm_live_..."})
print(r.json()["data"]["results"])

Endpoints

Endpoint Scope What it does
GET /v1/whoami any Shows your key's prefix, scopes, expiry and rate limit
GET /v1/categories knowledge:read Lists knowledge categories
GET /v1/knowledge/search?q=&category=&limit= knowledge:read Searches entries
GET /v1/knowledge/{id} knowledge:read Reads one entry
POST /v1/ask ask Answers a question from the knowledge base

Responses and errors

{"success": true,  "data": {...}, "request_id": "req_1a2b3c4d5e6f7a8b"}
{"success": false, "error": {"code": "INVALID_API_KEY", "message": "..."}, "request_id": "req_..."}

Status codes: 401 invalid, expired or revoked key (all look the same on purpose), 403 missing scope, 429 rate limit reached (see the Retry-After header). Every response carries X-Request-ID; quote it when you report a problem.

How your key is protected

  • Only a keyed hash of your key is stored, never the key itself. If our database leaked, the keys could not be recovered.
  • Keys can expire, be rotated with a grace period, or be revoked instantly.
  • Keep keys on your server. Anything placed in browser code can be read by visitors.
